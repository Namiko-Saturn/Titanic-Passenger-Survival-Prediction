### Titanic Passenger Survival Prediction

Project Overview

This project explores the Titanic passenger dataset using SQL to analyze the factors associated with passenger survival.

The analysis uses SQL queries to clean, filter, aggregate, and investigate passenger data, with a focus on identifying patterns in survival across demographic and passenger characteristics.

Project Objective

The objective of this project was to use SQL to explore passenger survival patterns and answer analytical questions about the Titanic dataset.

The project demonstrates how SQL can be used to transform raw data into meaningful insights through structured queries and exploratory analysis.

Dataset

The dataset contains information about Titanic passengers, including:

* Passenger ID
* Sex
* Age
* Passenger Class
* Number of Siblings/Spouses
* Number of Parents/Children
* Ticket
* Fare
* Cabin
* Embarkation Port
* Survival Status

SQL Analysis

The analysis explores questions such as:

* What percentage of passengers survived?
* How did survival differ by sex?
* How did survival vary across passenger classes?
* What was the survival rate by embarkation port?
* How did age relate to survival?
* What was the distribution of fares among passengers?
* How did family size relate to survival?
* How many missing values were present in key columns?

SQL Techniques Used

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* Aggregate functions
* COUNT()
* SUM()
* AVG()
* CASE WHEN
* Subqueries
* Filtering and conditional analysis
* Calculating percentages and rates

Key Findings

The SQL analysis was used to identify differences in survival outcomes across passenger demographics and characteristics.

The queries provide a structured way to compare survival patterns between groups and investigate relationships within the dataset.
